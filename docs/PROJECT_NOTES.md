## 1. Что это

- Публичный сайт-каталог брендов SpaceCam / R-Lock (ПТК, ООО «Технолайт», layta.ru):
  https://andreyshalnov.github.io/SpaceCam/
- Next.js static export на GitHub Pages, ветка `main`. Базовый путь `/SpaceCam`,
  маршрутизация хэшевая (`#/...`). Исходников (src/) в репо НЕТ — правки вносятся
  точечными патчами в собранные чанки `_next/static/chunks/*.js`.
- Главный чанк приложения (каталог, калькуляторы, админка, новости):
  `_next/static/chunks/8900f5fffe636865.js` (~218 КБ, минифицирован). Клиент Supabase — в чанке `df3ae3ca56794c86.js`.
- Кеш GitHub Pages: `max-age=600` → после деплоя проверять с `Ctrl+F5` или параметром `?v=<commit>`.
- Протокол правок: python-патч с уникальными якорями и count-проверками → `node --check` →
  commit → push → сборка Pages 1–3 мин → сверка md5 live-чанка с локальным → проверка в браузере.
- `index.html` в корне — prerendered главная: при изменениях шапки/футера синхронизировать вручную.

## 4. Ключевые механизмы в чанке 8900f5…

- `eW(sku)` — нормализация артикула (upper → кириллица→латиница → чистка → «(A)»→«-a» → lower):
  мост между вшитым каталогом (149 карточек в бандле) и таблицами БД.
- `eK()` / `eQ()` — загрузка цен/остатков **с пагинацией** `.range(o, o+999)` (PostgREST молча
  режет выборку до 1000 строк; `.offset()` в supabase-js v2 нет — регрессия a9a7906, хотфикс e2469b0).
- `eV(str)` — парсер числа: режет пробелы/NBSP, запятая→точка, ≥0, округление до 2 знаков.
- `eF2(num)` — формат отображения «123 134,4» (ru-RU, 0–2 знака) — показ значений в матрице «Цены».
- `t8` — общий класс input-ячеек матриц «Цены» и «Наличие» (text-center, tabular-nums).
- `nwsPage` / `nwsAdmin` — публичная страница и админ-вкладка «Новости» (CRUD через supabase).
- `sV` — админ-вкладка «Сверка наличия»: даты начала/конца периода из `stock_snapshots`,
  фильтр склада, агрегация «начало → конец → изменение», CSV; парсер Y0 читает 1С-отчёт
  «Анализ доступности товаров на складах» (SheetJS, чанк 70262): дата из шапки («Период: на
  конец дня ДД.ММ.ГГГГ»), склады по имени (краткие имена 1–8 + спецсклады 21–29),
  артикул = 2-й токен строки номенклатуры → `eW`; запись — апсёрт по 500 строк.
- Сравнение при сохранении в «Ценах» — числовое (`eV(a)===stored`), отформатированный показ
  не вызывает лишнюю запись.
